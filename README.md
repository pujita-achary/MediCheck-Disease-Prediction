# 🏥 MediCheck - AI-Powered Disease Prediction System

**Live Demo:** [Click Here to View App](https://medicheck-disease-prediction-bvsxg2zyydglvpii555bth.streamlit.app/)

## 📌 Overview
MediCheck is an end-to-end Machine Learning web application designed to predict the likelihood of multiple diseases based on user health metrics. The system provides real-time predictions for:
* **Diabetes** (Using Support Vector Machine)
* **Heart Disease** (Using Logistic Regression)
* **Parkinson's Disease** (Using Random Forest)

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **Frontend:** Streamlit
* **ML Libraries:** Scikit-Learn, Pandas, NumPy
* **Model Storage:** Pickle
